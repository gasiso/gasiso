<h3 align="center">Building tools to make my PC life easier ☕</h3>

<p align="center">
  I'm the kind of person who gets annoyed when having to do the same manual task twice. So, I build scripts and utilities to solve my own daily computer problems and automate the boring stuff.
  <br><br>
  I decided to start publishing these tools here on GitHub. If they save my time, maybe they can help you too! Feel free to use, modify, and share ideas. 🚀
</p>

### 🛠️ What I'm building

Here are some of the utility projects I developed for my personal use that are now open source:

<table>
  <tr>
    <td width="50%" valign="top">
      <b><a href="https://github.com/gasiso/AIO-Runtime-Installer">📦 AIO Runtime Installer</a></b><br>
      A smart PowerShell script that scans the PC and silently installs all essential Windows runtimes (C++, .NET, DirectX, etc). Perfect for fresh Windows installs!
    </td>
    <td width="50%" valign="top">
      <b><a href="https://github.com/gasiso/CoffeeAwake">☕ CoffeeAwake</a></b><br>
      An ultra-lightweight native C# tray utility that prevents the PC from sleeping using the Windows API, requiring no admin rights or fake keystrokes.
    </td>
  </tr>
</table>
